# AI-First Engineer Coding Lab

This directory contains the coding-heavy deliverables from the Groovy 30-Day checklist that can be completed independently of company Slack, paid API access, assigned client repositories, or senior review.

## Completed / included

- Day 3: reusable prompt library
- Day 5: Student Management CRUD — React + Node + PostgreSQL
- Days 6–9: provider CLI, multi-turn chat, streaming, retries, token telemetry, codebase explainer
- Days 10–12: Smart Document Q&A, local vector store, embeddings adapter, RAG, chunking comparison
- Days 13–15: tool-using agent, pure-SDK agent, optional LangChain/LlamaIndex adapters, real-use-case standup agent
- Day 19: CI workflow and Render deployment configuration

API-backed tasks use environment variables and also include local/mock paths where practical so the codebase can be inspected and exercised without exposing secrets.

See each day folder for exact run commands.
